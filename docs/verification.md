## 已通过的自动化覆盖

- 执行 `npm run check`、`npm test`、`npm run check:package`，结果如上。
- 确认 `/list` 沿用网页侧栏可见性：剔除子代理会话、剔除已归档会话，空的未使用会话仅在它是当前会话时保留。
- 确认 `/list` 排版带序号、行尾 ✅ 标记、相对时间与运行中标记，行首不带标记符号，输出受 15 条上限约束且单条不超 800 字符。
- 确认微信绑定的会话即使已归档也保留在 `/list`，行尾标「已归档 · ✅」；活跃度排序把它挤出 15 条时补在末行；绑定会话被删除时给出明确提示。
- 确认会话标题中的换行、C0/C1 控制字符与双向文本覆盖字符被压成单行，超长标题截断到 24 字符。
- 确认会话命令失败时微信仍收到提示，不会静默失败；`cancel` 同步抛错也计入失败数，不影响后续消息。
- 确认 `/switch <序号>` 改绑后后续消息提交到新会话，且切换只改绑定的会话，不调用 `create`。
- 确认 `/switch` 在缺少或过期 `/list`、序号越界、语法错误、目标已归档或不存在时拒绝并给出对应提示。
- 确认 `/switch` 只能落到 `/list` 实际渲染过的行：可见会话超过 15 个时，第 16 个序号被拒绝。
- 确认 `/switch` 的复核以当前绑定为基准：列表生成后变回空会话的目标会被拒绝，不会改绑到侧栏已隐藏的会话；`/SWITCH` 大小写不敏感。
- 确认 `/stop` 在 `cancel` 同步抛错时仍逐个调用并按失败数回复，`Promise.allSettled` 不会因同步异常被整体跳过。
- 确认 `/stop` 只停当前绑定会话：切换后旧会话里仍在跑的任务不受影响，`/stop all` 才停它。
- 确认 `/stop all` 只针对有在飞任务的会话，没有运行中任务时明确回复，未知作用域回用法提示。
- 确认 `/stop` 与 `/stop all` 在 `cancel` 同步抛错时仍逐项调用并回复（`/stop` 报失败，`/stop all` 汇总失败数）。
- 确认切换会话后，旧会话的审批与追问仍可由绑定用户回复；非绑定用户仍被拒绝。
- 确认 `archivedSessionIds` 经 `ctx.get('workspaceRegistry')` 可选读取，注册表缺失时返回空集合。
- 确认入站失败不重试，入站和出站失败或结果不明后仅留去重 ID，不留正文。
- 确认提交结果未知不重提，并提示状态不明、已丢弃，可在 Web 查看。
- 确认消息已从队列取出、提交尚未落盘时继续等待，取得真实回复而不是判为状态不明。
- 确认该窗口始终未落盘时按 60 秒宽限上限失败，不占用 30 分钟观察超时。
- 确认观察超时丢弃跟踪并提示到 Web 查看，DSH 任务仍可继续运行。
- 确认已明确提交的任务正常重启后继续观察，不重新提交；`queued` 未发送任务可恢复。
- 确认重启清理中断的 `sending` 及遗留失败、`uncertain`、`control-pending` 记录。
- 确认旧失败记录在存储打开时自动清理，绑定、游标和会话不变。
- 确认分段回复失败或结果不明后，尚未发送的后续段被丢弃，其他消息继续处理。
- 确认推送发送失败会按 5 秒、30 秒、2 分钟、6 分钟、15 秒的间隔重试，重试使用最新上下文；结果不明的失败不重试，重试耗尽后记入失败去重并丢弃。
- 确认 `-2 prepare failed` / `-14` 时先去掉 `context_token` 重发一次；去 token 仍返回 `-2` 时消息转入暂存，下次入站后补发，超过 24 小时或 20 条被清理。
- 确认 iLink 层仍仅对已知未接受的网络请求有限重试。
- 确认去重 ID 上限为最近 10,000 个；覆盖上限淘汰及非常旧重放的边界。
- 确认工具的 `queued` 不表示送达、`sent` 仅表示服务接受，失败去重结果不误报 `sent`。
- 确认离线恢复脚本及对应测试已删除，安装包不含该脚本。
- 真实环境（2026-10-29）：DSH 0.2.2-alpha.2 删除 `sessionController.inspect` 后，入站消息全部回复「任务准备失败」；0.5.9 改为有 `inspect` 用旧调用、否则用 `sessionQuery.observeSession`，重装后微信侧「测试」消息成功入库并回复。
- 真实环境（2026-10-30）：单条文字消息在准备阶段偶发失败，下一条正常；0.5.10 对「尚未提交」失败自动重试 2 次（1 秒、3 秒），并把最近 5 次失败的阶段、错误码、错误链、是否附带上下文 token 记录到状态接口，便于定位。
